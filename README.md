**WeLearn Student Management System** is a comprehensive, user-friendly, and organized student management system that streamlines course enrollment, department management, and academic records tracking for both students and teachers.

It aims to provide an efficient platform for managing academic activities, including course registration, information management, and department organization. The system ensures error-free navigation and input validation, allowing smooth interaction between students and teachers.  

**FEATURES**  
✅ Secure Login & Registration  
✅ Comprehensive department and course list (West Visayas State University)  
✅ For Teachers:  
- Assign a department/course  
- Remove a course  
- View courses  
- Edit/display personal information  

✅ For Students:  
- Enroll in a course  
- Drop a course  
- Edit/display personal information
